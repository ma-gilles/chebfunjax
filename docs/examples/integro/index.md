# Integral Equations Examples

Faithful replicas of the published chebfun.org `integro/` examples:
integro-differential equations, the Fox-Li operator, and fractional
calculus. (`IntegroDiffT` and `VlasovPoisson` exist only in the
chebfun/examples source repository — their chebfun.org pages are
unpublished, so they are not replicated here.)

| Example | Description |
|---------|-------------|
| [Eigenvalues of the Fox-Li integral operator (replica)](FoxLi.md) | Faithful replica: largest 80 eigenvalues spiral inside the unit circle. |
| [Fractional calculus in Chebfun (replica)](FracCalc.md) | Faithful replica: diff(f, alpha) / cumsum(f, alpha) fractional derivative and integral galleries. |
| [Fractional calculus: closed-form formulas (replica)](FracCalc2.md) | Faithful replica: Legendre/Chebyshev/Jacobi fractional-integral identities, Caputo vs RL. |
| [Wikipedia integro-differential equation (replica)](WikiIntegroDiff.md) | Faithful replica: chebop backslash with cumsum in the operator, eps-level accuracy. |
