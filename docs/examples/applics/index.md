# Applications (applics)

Faithful replicas of the published
[chebfun.org applics examples](https://www.chebfun.org/examples/applics/).

| Example | Description |
|---------|-------------|
| [Spread option in 2D Black-Scholes](BlackScholes2D.md) | The spread-option price as a Chebfun3 of (T, K, ρ); Tucker core 5×10×7 matching MATLAB. |
| [The AAA algorithm for system identification](Bode2tf.md) | LTI poles, zeros, and DC gain from Bode plots via AAA and AAA-LS; noisy-data identification. |
| [Pricing of a European Call option](EuropeanCall.md) | Risk-neutral pricing with chebfuns of the lognormal density; Black-Scholes comparison. |
| [Pricing other European Options: Puts, Digitals, Powers](EuropeanOptions.md) | The payoff-distribution method for puts, digital, and power options — 14-digit parity. |
| [Exponential, logistic, and Gompertz growth](Gompertz.md) | Population-growth IVPs solved with chebop. |
| [Accurate Greeks](Greeks.md) | Risk sensitivities by differentiating chebfun2 slices of the payoff density. |
| [The AAA algorithm for system identification (2)](Step2tf.md) | Step-response system identification with AAA + FFT + Vandermonde with Arnoldi. |
| [Exploring Vanilla Options](VanillaOptions.md) | Black-Scholes calls and puts vs maturity and rates; hedging strategies; early-exercise boundary. |
