# PDE Examples

translations of all 10 published chebfun.org `pde` examples.
Each page links its original, and each translation script regenerates the
figures and printed outputs.

| Example | Summary |
|---|---|
| [Black-Scholes PDE using operator exponential](BSExponential.md) | v(55) to 5 digits; piecewise-expm gap ledgered. |
| [Heat equation via expm](Erosion.md) | Erosion curves point-for-point at t=0.1. |
| [Time-dependent PDEs on a periodic interval with expm](FourierExpm.md) | Heat decay e^-9 to 7 digits; coherent convection. |
| [Complex Ginzburg-Landau equation in 2D](GinzburgLandau.md) | Arm-for-arm spirals; diagonal symmetry preserved at t=48. |
| [Gray-Scott equations in 2D](GrayScott.md) | Rolls/spots; tilted-symmetry test 1.4% vs 70%. |
| [Traveling waves of the KS equations](KSWave.md) | All four stability verdicts reproduced. |
| [KdV solitons and non-solitons](KdV.md) | 13-digit conserved quantities; 9-digit soliton amplitude. |
| [Kuramoto-Sivashinsky equation and chaos](Kuramoto.md) | Crest-for-crest chaotic waveform at t=100. |
| [Swift-Hohenberg equation in 2D](SwiftHohenberg.md) | Spot-for-spot pattern; refinement error exactly 3.63e-04. |
| [Eigenvalues of a trapezoidal drum](TrapezoidEigs.md) | Method of particular solutions; 3.8984, 5.433, 6.70. |

(The chebfun GitHub sources AllenCahn2, IntegroDiffT, Maxwell,
ReactDiffSys, and SVDFrequencyResponse have no published pages on
chebfun.org and are not replicated.)
