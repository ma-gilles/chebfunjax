# Random ODE Examples

These examples demonstrate random ODEs driven by smooth band-limited random
functions (`randnfun`), and their connections to stochastic differential equations.

| Example | Description |
|---------|-------------|
| [Collective dynamics and consensus](Consensus.md) | translation: random walks locking together under short-range attraction. |
| [Geometric Brownian motion](GBM.md) | translation: multiplicative noise, three drift regimes. |
| [Random level hopping](LevelHopping.md) | translation: integer-level hopping; found+fixed a silent marcher fallback. |
| [Phase-locking in a Duffing-type equation](PhaseLocking.md) | translation: 60 paths locking onto the sqrt(t) branches. |
| [Pitchfork bifurcation triggered by noise](Pitchfork.md) | translation: swept pitchfork, branch endpoints at sqrt(c/2). |
| [From random functions to SDEs](Random2SDE.md) | translation: smooth random walks, lambda = 0.001. |
| [Random trajectory on a sphere](RandomOnASphere.md) | translation: energy conserved to 5e-10 radius drift. |
| [Linear ODEs with random switching](RandomSwitching.md) | translation: decay/grow/decay across the three switching rates. |
| [Tunnelling](Tunnelling.md) | translation: bistable metastable switching; exponential noise sensitivity. |
| [The white noise paradox](WhiteNoiseParadox.md) | translation: randnfun 'big' amplitude growth as lambda -> 0. |
